# Players for TMDb Helper

The open-players pack plus players for Seren, Prism, Red Light and Otaku Testing, used with the TMDb Helper fork in this repository.

TMDb Helper -> Settings -> Players -> Install players -> Install from URL, and enter:

`https://raw.githubusercontent.com/minhgi/tmdbhelper-multiservice/main/players/tmdbhelper_players.zip`

(`tmdbhelper_players.zip` in this folder is the same set zipped; it can also be installed with Install from zip file.)
